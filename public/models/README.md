Put your cup model files in this folder.

Expected file names:

- simple_mug.glb
- coffee-mug.glb

The product data in `backend/src/models/product.js` points to these public URLs:

- `/models/simple_mug.glb`
- `/models/coffee-mug.glb`

Use `.glb` when possible because it keeps geometry, materials, and textures in one file.
